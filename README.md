## ✨ このリポジトリでできること

- 日本語版 D2L を **オンラインで閲覧** できます（GitHub Pages）。
- `docs/` の静的 HTML を **自動デプロイ** できます。
- 章ごとの改善提案や翻訳の更新に **参加** できます。

## 🤝 Contribute（貢献）

このオープンソース書籍は、コミュニティの方々からの提案や誤字・脱字の修正により支えられています。  
より良い内容へ更新するために、あなたの協力が必要です。私たちは[謝辞](http://en.diveintodeeplearning.org/chapter_introduction/preface.html#Acknowledgments)に協力者の名前を記載します。

協力される方は、[issue](https://github.com/harusametime/d2l-ja/issues)でご連絡ください。最初に PR を送っていただいても構いません。

## 🚀 GitHub Pages（HTML 公開）

`docs/` 配下の静的 HTML を GitHub Pages で公開しています。  
公開先はこちら：**https://harusametime.github.io/d2l-ja/**

### 設定手順（GitHub Actions デプロイ）
1. **Settings → Pages** を開く。
2. **Source** を「GitHub Actions」に設定する。
3. `main` ブランチへ push するとデプロイが走る。

公開されるトップページは `docs/index.html` です。
